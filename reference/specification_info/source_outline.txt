## Master Small GI Specification Rev C.docx (small-project flavour)
   Body paragraphs: 286
   Tables         : 8

## Key finding

Master GI Spec rev D uses the SAME Schedule 1-5 taxonomy as the .docm
(with slightly more content). It references "Specification Section 3",
"Section 4" etc. but does NOT contain the main Specification body --
those sections live in an EXTERNAL document not in this reference tree.

Master Small GI Specification Rev C is a completely DIFFERENT document type
-- a self-contained "small GI" spec with its own flat structure
(Introduction / Ground Investigation Schedule / Sampling Requirements /
Lab Testing / Reporting / Further Information). It does not use the
Schedule 1-5 taxonomy at all.

## Implication for build plan

The "main Specification body (Sections 1-16)" that S1.x cross-references
is not available in our reference folder. Generating "full spec + schedules"
as one standalone document therefore means one of:
(a) Adopt Master Small GI Spec Rev C style as the main body, drop the
    Schedule 1-5 numbering in favour of its simpler chapter structure.
(b) Keep the Schedule 1-5 structure from the .docm but add our own
    "Section 1-16" main body -- would require sourcing/drafting from
    scratch or from an external standard (TII/OPW).
(c) Schedules only (the original plan), accept that the main body
    attaches separately.
